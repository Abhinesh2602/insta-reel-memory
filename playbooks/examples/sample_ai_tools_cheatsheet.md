## 2. Tactics & Techniques
- **Scroll-animation pipeline (Apple-style)**: Google Whisk → generate start/end keyframes with a prompt; Google Flow → "frames to video" to animate between them; EasyGif → split the video into ~240 frames at 30fps; drop frames into your code project + a scroll-sync prompt to get buttery scroll-triggered animation [@builtbyprajwal](https://www.instagram.com/reel/DUXqv2eCMxC/).
- **"Go inside the product" VFX transition**: shoot/generate 4 images (2 of the product, 1 entering, 1 inside) → Google Flow First/Last-Frame with Veo3 to generate the connecting clips → pre-compose in After Effects → Layer > Time > Timewarp → keyframe + Easy Ease (F9) → add speed ramping [@rourke](https://www.instagram.com/reel/DTLKLwXE8_p/).
- **CGI product shot pipeline**: find a CGI-style Pinterest reference → feed it + a detailed scene prompt to ChatGPT image gen → optionally animate the result in Wan (free) for a finished CGI ad [@heysirio](https://www.instagram.com/reel/DHtgdQAP3RI/).
- **Custom font from one inspo image**: prompt ChatGPT to generate a full A-Z/0-9 glyph sheet matching a reference logo's style → vectorize each letter individually in Illustrator → export SVGs → convert to a real font file with Calligraphr; same technique re-skins existing Instagram templates by regenerating just the text [@heysirio](https://www.instagram.com/reel/DHygI1KgGJ9/).
- **Bulk SEO URL/meta rewrite**: export URL+title table from Looker Studio (3-dot menu → export chart/data) → paste into Claude with a "rewrite to match intent, return CSV (old url, new url, new title)" prompt → Claude returns rewritten H1/meta/slug for thousands of URLs in minutes instead of a $3k/month agency retainer [@iojeet](https://www.instagram.com/reel/DXcMbp5kunY/).
- **GEO / AI-search targeting**: ask ChatGPT a comparison question, inspect the Network tab request after `/c`, read the "queries" field in the response to see its literal search terms, then build YouTube videos + website sections using that exact language (YouTube gets cited more than Reddit in LLM answers) [@edward.builds](https://www.instagram.com/reel/DUeHCDojBJ3/).
- **Book-compression reading hack**: feed a non-fiction book's content to a deep-research tool (OpenAI's Deep Research outperforms Perplexity/Grok here) to compress 300-page filler books into 30-50 page dense summaries without losing the core insight/data/story elements [@thevarunmayya](https://www.instagram.com/reel/DG0xuofILqE/).
- **Pre-launch checklist for vibe-coded apps**: publish a privacy policy if collecting user data; check OWASP basics (SQLi, XSS, broken auth); confirm `.env` isn't committed and is gitignored, scrub secrets from logs; add API rate limits before someone drains your bill in one night [@sanket_agent](https://www.instagram.com/reel/DYZqGPVpyZt/).
- **Claude Code project hygiene**: keep a global `CLAUDE.md` (cross-project style/behavior rules only) + global skills/agents reserved for truly universal workflows (e.g. a planning skill); put tech-stack/folder-structure/deploy notes and project-specific skills at the project level — project skills don't leak into other projects [@mavenhq](https://www.instagram.com/reel/DVOzQtcD0oM/).
- **Multi-tool vibe-coding stack**: Claude Code (research, skills, prompting) + Antigravity IDE (UI/UX layout work only, not invention) + Firecrawl (research reference sites like Linear/Supabase/Notion) + Whisper Flow (voice-to-text, ~10k words/day into the pipeline) + a "Get Should Done" orchestration repo for checkpoints/validators — each terminal/agent gets one scoped role instead of one agent doing everything [@daviss.dev](https://www.instagram.com/reel/DTbbY_FjeXT/).
